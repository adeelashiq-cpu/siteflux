FAQ

Frequently asked questions

Are these tools completely free to use?

Yes. Siteflux is 100% free and open. There are no subscriptions, hidden limits, or user registration requirements.

Does Siteflux store or track any of my data?

No. All calculations, previews, and generators run locally in your client's JavaScript engine. Checklist progress is stored securely in your browser's private localStorage.

Can I use this offline or install it as a desktop shortcut?

Yes. Because there is no backend server requirement, you can save the page or run it entirely offline with complete functionality.

How can I export my launch checklist to share with my team or client?

Click the "Export as Markdown" button at the bottom of the checklist. It generates a formatted markdown task list ready to paste directly into GitHub Issues, Notion, Slack, or Linear.
