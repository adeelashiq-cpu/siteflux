# WebLaunch Tools

A responsive static website containing six working browser-based tools:

- Meta Tag Generator
- SERP Preview
- Robots.txt Generator
- Schema JSON-LD Generator
- UTM Campaign Builder
- Website Launch Checklist with localStorage

## Run locally
Open `index.html` directly, or use any static server.

## Deploy
Upload the folder to Netlify, Vercel, GitHub Pages or Hostinger public_html.

## Before production
Replace `https://example.com/` in `index.html` with your real domain and add your own logo, analytics, privacy page and monetization scripts if needed.
